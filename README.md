# Pip's Dream World — Baby's First Website Hackathon (Track 1)

A responsive, mobile-friendly single-page portfolio built with plain HTML, CSS and JavaScript. Uses the official Pip PNG assets supplied in the Track 1 asset pack.

## Included interactions
- Responsive layout and day/night toggle
- Pip greeting button with randomized reactions
- Three showcase projects with working interactions
- Original short browser-generated lullaby using the Web Audio API (no audio file or external service needed)
- Click-through bedtime story and secret Easter egg
- Keyboard-friendly native buttons and live status text

## Run locally
Open `index.html` in a browser. Keep the `assets` folder beside it.

## Deploy with Netlify from a phone
1. Extract `pips-dream-world.zip` on your phone.
2. Open Netlify Drop in your browser: https://app.netlify.com/drop
3. Sign in / create an account if asked.
4. Upload the extracted `pips-dream-world` folder (or, if the page accepts it, drag the ZIP). If folder upload isn't supported on your phone, use the GitHub method below.
5. Open the generated site URL and test all buttons.

## Deploy with GitHub Pages
1. Create a public GitHub repository named `pips-dream-world`.
2. Upload `index.html` and the entire `assets` folder (not the ZIP itself).
3. In repository Settings → Pages, choose deploy from branch `main`, folder `/ (root)`, then Save.
4. Wait for the published URL, open it on mobile, and test every interaction.
